# 1. Примитивная база данных

Полноценное консольное приложение, имитирующее работу с базой данных, которое можно установить и запустить как самостоятельный пакет.

## 2. Инструменты

- **Python 3.12** — базовые структуры, работа с файлами JSON, обработка исключений и использование декораторов.
- **uv** — управление проектом и зависимостями.
- **Ruff** — линтер для проверки стиля кода (PEP 8).
- **Git** — контроль версий.
- **prettytable** — для форматированного вывода таблиц в консоль.

## 4. Управление таблицами

Взаимодействие с базой данных происходит через консольный интерфейс с помощью текстовых команд.

### Доступные команды:
* `create_table <имя_таблицы> <столбец1:тип> ...` — создает новую таблицу. Поддерживаемые типы: `int`, `str`, `bool`. Столбец `ID:int` создаётся автоматически.
* `list_tables` — выводит список всех существующих таблиц.
* `drop_table <имя_таблицы>` — удаляет выбранную таблицу (запрашивает подтверждение).
* `help` — выводит справочную информацию на экран.
* `exit` — завершает сессию работы.

## 5. CRUD-операции с данными

* `insert into <имя_таблицы> values (<значение1>, <значение2>...)` — добавляет новую запись. ID генерируется автоматически.
* `select from <имя_таблицы>` — выводит все записи в виде красивой таблицы.
* `select from <имя_таблицы> where <столбец> = <значение>` — выводит записи по условию.
* `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновляет записи.
* `delete from <имя_таблицы> where <столбец> = <значение>` — удаляет записи (запрашивает подтверждение).
* `info <имя_таблицы>` — выводит схему таблицы и количество записей.

### Пример использования:

```text
>>> Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

>>> Введите команду: insert into users values ("Ivan", 25)
Запись с ID=1 успешно добавлена в таблицу "users".

>>> Введите команду: select from users where age = 25
+----+------+-----+
| ID | name | age |
+----+------+-----+
| 1  | Ivan | 25  |
+----+------+-----+

>>> Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".
```

## 6. Продвинутые механики

В проекте реализованы декораторы (в `core.py` и `decorators.py`):
- `handle_db_errors` — обрабатывает ошибки БД.
- `confirm_action` — запрашивает подтверждение `[y/n]` перед удалением данных.
- `log_time` — замеряет время выполнения операций.
- Кэширование реализовано через замыкание `create_cacher` и используется при выборке данных (`select`).

## 7. Запуск проекта и линтера

**Запуск базы данных:**
```
uv run database
```

**Проверка стиля кода и форматирования (Ruff):**
```
uv run ruff check .
```
