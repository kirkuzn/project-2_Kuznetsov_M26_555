# 1. Примитивная база данных

Проект консольной реляционной базы данных на основе JSON, включающий 6 этапов разработки.

## 2. Инструменты

- **Python 3.12** — базовые структуры, работа с файлами JSON, обработка исключений и использование декораторов.
- **uv** — управление проектом и зависимостями.
- **Ruff** — линтер для проверки стиля кода и форматирования.
- **Git** — контроль версий.

## 4. Управление таблицами

Взаимодействие с базой данных происходит через консольный интерфейс с помощью текстовых команд.

### Доступные команды:
* `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создает новую таблицу. Поддерживаемые типы данных: `int`, `str`, `bool`. Столбец `ID:int` создаётся автоматически.
* `list_tables` — выводит список всех существующих таблиц.
* `drop_table <имя_таблицы>` — удаляет выбранную таблицу и все её данные.
* `help` — выводит справочную информацию на экран.
* `exit` — завершает сессию работы.

### Пример использования:

```text
>>> Введите команду: create_table table1 name:str age:int is_active:bool
Таблица "table1" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>> Введите команду: list_tables
- table1

>>> Введите команду: drop_table table1
Таблица "table1" успешно удалена.
```

## 5. Запуск проекта и линтера

**Запуск базы данных:**
```
uv run project
```

**Проверка стиля кода и форматирования (Ruff):**
```
uv run ruff check .
```
